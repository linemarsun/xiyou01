# 山海奇谭（shanhai）

一款大话西游式 **2D 回合制 RPG** 的原创实现。当前已完成到 **模块 12（一景一制）**：五张地图（云京 + 青崖山道 / 渡忘川 / 玲珑洞天 / 地府）各有独立格网尺寸、轮廓形状、路网骨架与地标组合，出入口一律贴在地图边界；可在浏览器里从选人 → 大地图探索 → 遭遇战 → 结算成长，走完整条单机流程。

> ⚠️ 本项目只借鉴回合制玩法机制（机制不受版权保护）；美术、名称、文案、素材全部原创，不使用任何网易素材。

## 运行

```bash
npm install
npm run dev      # http://localhost:5199
npm run build    # tsc --noEmit + vite build
npm run preview  # 预览构建产物
npm run assets   # 重新生成像素素材（public/assets/）
npm run maps     # 重新生成四张野外/地府等距布局（各自尺寸/路网，幂等）
```

地址栏加 `#sim` 进入**数值仿真**：AI 执挥双方批量跑 144 场完整战斗，输出各职业胜率与平均回合数，用于调平衡。

## 当前功能概览

- **M1 战斗核心**：大话式回合流程（统一下指令 → 按速度结算），指令/事件流 + 种子化 RNG；四门派职业（司礼府 / 琼霄仙府 / 玄炎魔窟 / 忘川幽祠）、控制与抗性博弈、宠物、道具、敌方 AI、选人界面。
- **M1.5 战斗 2.5D 化**：PixiJS 斜透视场景 + 像素精灵（待机/走路/攻击/施法/倒地）+ Y 排序与纵深 + 血蓝条/状态章 + 法术粒子 + 伤害飘字；指令面板与战斗日志仍是 DOM。
- **M2 / 模块 12 大地图探索**：云京 → 青崖山道 → 渡忘川 / 玲珑洞天 → 忘川南渡口 → 地府（战败重生）→ 还阳回云京，**五张各有独立格网的等距构件地图**（云京 128×128、山道 128×96、忘川 96×128、洞天 104×104、地府 80×112），格级 BFS 寻路与碰撞、点击走路自动吸附最近可走格、所有出入口贴边界且成对回程；玄鹤长老三环任务链、野外遇敌、银两/丹药/装备掉落、localStorage 自动存档与「继续冒险」。
- **M2.1 自动战斗**：与敌方 AI 同源的自动指令 + 濒危嗑药，出手前可随时切回手动。
- **M2.5 捕捉召唤兽**：战斗内捕捉（血越少成功率越高，头目不可收服）、宠物栏上限 6、切换出战宠物。
- **M3a 装备与等级**：三部位 × 三品阶装备、穿戴/卸下、炼化重掷词条（30 银）；人物等级/经验、四维潜能加点、战斗属性加成。
- **M3b 召唤兽个体化**：宠物实例（uid/物种/等级/经验），出战宠物打怪得经验升级、每级全属性 +8%，收服的怪按人物等级入栏。
- **M3c 师门法术等级**：法术 1~10 级，威力/命中/持续回合/MP 随级成长（Lv6 起 +1 回合）；世界界面「📜 师门」用银两 + 潜能修炼。
- **模块 1 回归自检**：`npm test` 在 Node 侧断言三环任务链、结算/存档迁移、战斗可复现性与素材清单契约。
- **模块 2 装备系统补全**：宠物护甲/饰品装备位（与人物共用装备池）、按怪物难度的掉落品阶池、极品 ★稀有词条、洗点丹。
- **模块 3 / M3d 宠物炼妖**：两只非出战召唤兽合成一只，物种/等级/技能继承 + 随机成长系数，20% 概率领悟新增通用技能；宠物面板可直接操作。
- **模块 4 组队同伴**：云京酒馆雇佣最多 2 名 AI 同伴（复用职业数值/技能/精灵），进入人物排统一指挥、自动战斗接管，等级跟随人物。
- **模块 5 音乐音效**：Web Audio 实时合成三档 BGM 与 11 类战斗音效（零音频素材），选人/世界/战斗三处静音开关并记住偏好。
- **模块 6 自动战斗 + 自动寻路**：HUD「🤖 挂机」一键托管，自动找怪 / 跨图巡游 / 自动回镇接交任务 / 战斗内自动接管；点击移动与挂机共用 waypoint 路径管线。
- **模块 7 / 12 等距地图体系**：`core/iso.ts` 定义 2:1 菱形格网、构件足迹、碰撞与格级 BFS；`core/world.ts` 的 `ISO_GRIDS` 为每张图单独定义格网，世界尺寸与 bounds 由格网推导。云京是城墙四门 / 中心鼓楼 / 四坊的城制样板；四张野外各有专属路网。渲染层按镜头裁剪合成构件，缺图走程序化占位；旧满幅背景仅作为回退资源保留。
- **模块 8 国风美术风格**：接入「原创国风西游」引擎素材（云纹木框 UI、Q版头像、国风图标、满幅战斗背景），CSS 与程序化场景统一到朱红/靛青/赭金/米白；映射集中在 `src/core/art.ts`。
- **模块 9 世界观文案统一**：地名/任务/NPC/怪物/职业/灵兽统一到云京五族设定，id 与数值不变、老存档兼容。
- **模块 10 国风地图与悬赏榜**：世界地图改用参考满幅国风背景（奇偶列镜像拼接无缝），任务界面改云纹木框悬赏榜（任务卡/进度条/赏格），HUD「📜 悬赏」可随时只读查看。
- **模块 11 等距野外全场景**：青崖山道 / 渡忘川 / 玲珑洞天 / 地府从旧横向卷轴改为等距构件地图，玩法锚点格坐标化，跨图落点与战败重生同步。
- **模块 12 一景一制**：四张图不再共用十字广场与中心券门，改为各自独立的尺寸、形状与路网——青崖山道 128×96 盘山之字栈道 + 三溪石桥 + 林海；渡忘川 96×128 忘川斜贯 + 两岸石堤 + 六渡石桥 + 枯木；玲珑洞天 104×104 青苔环廊 + 青石圆厅 + 四向放射石阶 + 晶壁；地府 80×112 黄泉直道 + 忘川横河 + 奈何桥 + 碑阵引魂灯。全部出入口贴在格网边界带，成对路牌互为对方落点；`npm test` 锁住独立格网、边界锚点、锚点一致性、全锚点 BFS 连通与主题差异。

素材全部由 `tools/gen-assets.mjs` **程序化生成**（风格统一的原创像素画，零版权风险）：改生成器调色板/造型参数后跑 `npm run assets`；或按 `public/assets/manifest.json` 清单里的文件名逐张替换 PNG，代码无需改动。详见 [使用方式.md 第 7 节](./docs/使用方式.md)。

## 架构（为联机预留）

```
src/core/    纯逻辑层，禁止 import DOM
  rng.ts       可种子化随机数（同种子+同指令 ⇒ 同结果，可回放可同步）
  audio-map.ts 战斗事件 → 音效名（纯函数，供浏览器音频层与回归断言消费）
  path.ts      waypoint 路径规划（当前单段直线 + 边界钳制，可替换为 A*）
  autoplay.ts  挂机决策纯函数（找怪 / 跨图 / 交任务 / 停止）
  art.ts       国风素材映射与主色（纯数据配置）
  types.ts     单位/技能/指令/事件类型 —— 指令与事件全是可序列化纯对象
  content.ts   全部数值与文案（调平衡只改这里）
  battle.ts    战斗引擎：resolveRound(playerCommands) => BattleEvent[]
  ai.ts        敌方 AI（纯函数，将来可原样跑在服务器）
  skill.ts     师门法术等级换算
  equipment.ts 装备生成/词条/加成
  world.ts     地图（ISO_GRIDS 每图一规格网 + 边界锚点 + 按目标图换算落点）、任务、掉落、存档
  iso.ts       等距格网数据结构/构件足迹/碰撞/格级 BFS 寻路（与格网尺寸无关）
  sim.ts       数值仿真（批量 AI vs AI）
src/render/  PixiJS 2.5D 渲染层
  battle-renderer.ts  场景/精灵/血条/Y排序/光环/倒地
  world-renderer.ts   等距构件合成与视口裁剪/走路/游荡/触发（缺图程序化占位）
  particles.ts        法术特效（汇聚/爆散/上升气泡）
  tween.ts            极简补间动画
src/ui/      浏览器层：选人、世界 HUD/面板、指挥面板、战斗日志、事件流播放
src/audio/   Web Audio 音频层：三档 BGM、事件音效、静音偏好
tools/gen-assets.mjs  像素资产生成器
tools/regression.mjs  Node 侧全链回归自检
docs/        功能说明 / 接口说明 / 使用方式
```

联机路径已铺好：客户端只上传 `Command[]`，服务器运行同一份 `resolveRound` 下发事件流；渲染层与 DOM UI 都只消费事件流，天然支持服务器授权。

## 数值速查

职业/宠物/怪物/技能/遭遇的全部数值集中在 `src/core/content.ts`，改完刷新即生效；伤害与状态规则在 `src/core/battle.ts`，师门成长在 `src/core/skill.ts`，掉落/经验/任务在 `src/core/world.ts`。改动后跑 `#sim` 看胜率。

地图布局改 `tools/gen-iso-maps.mjs` 后执行 `npm run maps`（幂等，生成器自带 BFS 自检），产物是 `public/assets/art/iso/<region>.json`；布局的 `grid` 必须与 `src/core/world.ts` 的 `ISO_GRIDS[region]` 一致，`anchors`（怪组 / 边界路牌 / NPC / 跨图落点格坐标）必须与 `BASE_MAPS` 逐条一致。`npm test` 会校验两者、边界带、按目标图格网换算的落点、所有玩法点两两 BFS 连通与四图主题差异。
