# 山海奇谭（shanhai）

一款大话西游式 **2D 回合制 RPG** 的原创实现。当前为 **M1 战斗核心原型**：能在浏览器里打一场完整的遭遇战。

> ⚠️ 本项目只借鉴回合制玩法机制（机制不受版权保护）；美术、名称、文案全部原创，不使用任何网易素材。

## 运行

```bash
npm install
npm run dev      # http://localhost:5199
npm run build    # 类型检查 + 打包
npm run assets   # 重新生成像素素材（public/assets/）
```

地址栏加 `#sim` 进入**数值仿真**：AI 执挥双方批量跑 144 场完整战斗，输出各职业胜率与平均回合数，用于调平衡。

## 2.5D 画面（M1.5）

战斗场景为 PixiJS 渲染的 2.5D 画面：斜透视手绘风场景图 + 像素小精灵（待机/攻击/施法/倒地动画）+ 脚底 Y 排序 + 近大远小纵深 + 粒子法术特效 + 伤害飘字。指令面板与战斗日志仍是 DOM。

素材全部由 `tools/gen-assets.mjs` **程序化生成**（风格统一的原创像素画，零版权风险）：

- 想调整画面：改生成器里的调色板/造型参数后跑 `npm run assets`；
- 想换成手绘或下载的素材：按 `public/assets/manifest.json` 清单里的文件名逐张替换 PNG 即可，代码无需改动（清单定义了每个角色的帧序列、帧率与循环方式）。

## 大地图探索（M2）

选人后进入开放世界：**桃源镇**（安全区）→ **黑风岭** → **乱葬岗** / **千年山魈岭**，四张 1440×900 大图摄像机卷动，点击地面走路（点路牌/NPC/怪物会自动吸附走过去）。

- **NPC 任务链**：缉妖司长老三连任务——缉狼令（野狼×3）→ 净乱葬（骷髅/蜘蛛×4）→ 讨山魈（山魈王×1），完成领赏银与丹药；
- **野外遇敌**：怪物在地图上游荡，走近即触发遭遇战（一组怪一场仗）；
- **奖励经济**：胜利得银两 + 随机掉落丹药，背包里的丹药就是战斗中的道具（打完按实际消耗扣账）；
- **自动存档**：任务、战斗结算、切图自动存 localStorage，选人界面可「继续冒险」。

## M1 已有内容

- **大话式回合流程**：每回合开始为所有己方单位（主角 + 宠物）依次下指令 → 点「出手」按速度顺序结算。
- **门派与职业**（参考大话门派体系，命名全部原创）：侠客·**缉妖司**（人 · 物理+封印/混乱双控制）、灵官·**紫霄宫**（仙 · 风/火/雷/水四系仙法）、魔师·**血狼堡**（魔 · 加攻+重击+摄血还身）、巫祝·**酆都祠**（鬼 · 遗忘+三尸蛊毒）。
- **状态与抗性博弈**：混乱 / 昏睡（受击即醒）/ 封印 / 遗忘 / 蚀毒（DoT）+ 攻升 / 防升增益；每种控制与每系法术都有对应抗性，命中 = 基础命中率 − 目标抗性。
- **宠物**：灵狐（快 · 催眠）、岩甲兽（坦 · 铁壁）、雷隼（爆发 · 落雷/疾风）。
- **遭遇战 ×3**：黑风岭劫道 / 乱葬岗魅影 / 千年山魈（含会给自己加攻的头目）。
- **道具**：金疮药（回血）/ 凝气丹（回蓝），每场各 3 个。
- **敌方 AI**：增益 → 控制（对正确抗性最低的目标）→ 输出 → 普攻；一半概率补刀残血。
- **战斗记录 / 飘字 / 会心一击 / 速度 ×2 / 自动战斗** 等 UI 细节。自动战斗与敌方 AI 同源（增益→控制→输出→普攻），外加濒危自动嗑金疮药；出手前关掉开关可回到手动指挥。

## 架构（为联机预留）

```
src/core/    纯逻辑层，禁止 import DOM
  rng.ts       可种子化随机数（同种子+同指令 ⇒ 同结果，可回放可同步）
  types.ts     单位/技能/指令/事件类型 —— 指令与事件全是可序列化纯对象
  content.ts   全部数值与文案（调平衡只改这里）
  battle.ts    战斗引擎：resolveRound(playerCommands) => BattleEvent[]
  ai.ts        敌方 AI（纯函数，将来可原样跑在服务器）
  sim.ts       数值仿真（批量 AI vs AI）
src/render/  PixiJS 2.5D 渲染层
  battle-renderer.ts  场景/精灵/血条/Y排序/光环/倒地
  particles.ts        法术特效（汇聚/爆散/上升气泡）
  tween.ts            极简补间动画
src/ui/      浏览器层：选人、指挥面板、战斗日志、事件流播放
tools/gen-assets.mjs  像素资产生成器
```

联机路径已铺好：客户端只上传 `Command[]`，服务器运行同一份 `resolveRound` 下发事件流；渲染层与 DOM UI 都只消费事件流，天然支持服务器授权。

## 路线图

- **M2**：大地图移动、NPC 对话、任务、战斗奖励与掉落

## 数值速查

职业/宠物/怪物/技能/遭遇的全部数值集中在 `src/core/content.ts`，改完刷新即生效。
