## 2. 当前游戏内容清单

### 战斗（大话式：回合开始统一下指令 → 按速度结算）
- **门派与职业**：云岚·司礼府（人，武技+混乱/封印/昏睡三控）、霜华·琼霄仙府（仙，风/火/雷/水四系）、玄烬·玄炎魔窟（魔，加攻/重击/摄血吸血）、冥汐·忘川幽祠（鬼，遗忘/三尸蛊/鬼火）。
- **师门法术等级**：每系法术 Lv.1~10——威力随级 +6~7%/级、控制命中 +1.5%/级、Lv.6 起持续回合 +1、MP 消耗随级递增；世界界面「📜 师门」用银两+潜能修炼（40×N 银 + N 潜），战斗内施放按当前等级实时换算。
- **状态与抗性**：混乱（敌我不分）、昏睡（受击即醒）、封印、遗忘、三尸毒 + 火/水/风/雷抗性；控制命中 = clamp(基础命中率 − 目标抗性, 5, 95)，元素抗性另按 `min(抗性,75)` 折算伤害系数。
- **指令**：攻击 / 法术 / 道具（金疮药回血、凝气丹回蓝）/ 防御 / 捕捉（仅人物，血越少越易收服，山魈王不可收）。
- **站位**：左右对峙——敌方左列 5 槽，我方右列两排（人物排 + 宠物排在前），各容 5 槽；攻击突进左右对冲。
- **敌方 AI**：增益 → 控制（挑抗性最低目标）→ 输出 → 补刀；自动战斗与它同源，外加濒危自动嗑药。
- **数值仿真**：`#sim` 当前胜率约 50%/61%/75%/56%（云岚控制流在 AI 手里偏低，真人更高；数值改动后需重跑）。

### 世界
- **地图**：云京（安全区，NPC 玄鹤长老）→ 青崖山道（青崖苍狼×3 组、玄石熊罴）→ 渡忘川（忘川骨卒×2 组、幽丝蛛妖）→ 玲珑洞天（山魈×2 组、洞天山魈王）。出口路牌点击即走。每张图为**横向分块卷轴** `11520×900`（`WORLD_SCALE=8` 个区段），怪组/出口按区段复制补充，长老与酒馆在起点区段，走路速度 200 px/s。
- **任务链**（顺序解锁）：青崖清狼（青崖苍狼×3，赏 100 银+金疮药×2）→ 忘川镇骨（骷髅/蜘蛛×4，赏 160 银+凝气丹×2）→ 洞天讨魈（山魈王×1，赏 300 银+丹药×3）。
- **经济**：银两按怪物掉落；战斗掉落丹药；背包丹药 = 战斗道具（按实际消耗扣账）。
- **装备**：武器（攻）/护甲（防+气血）/饰品（法或速+气血）三部位，凡品/良品/极品三阶；打怪掉落（头目必掉、普通怪 18%，品阶按 `DROP_TIER_WEIGHTS` 怪物难度权重），背包上限 12；人物加成经 `playerBonus` 只作用于主角，出战召唤兽可穿护甲/饰品（`petBonus` 只作用于宠物），共用背包不可一件两穿；炼化花 30 银重掷词条（极品 25% 出 ★稀有词条、数值 ×2、炼化会重掷）；洗点丹清空加点并全额退还潜能（青崖清狼/头目必掉/普通 8%）。
- **等级经验与加点**：经验按怪物给（青崖苍狼 18 …… 山魈王 120），升级需求 `40 + 35×当前等级`，**每级 +5 潜能点**；加点四维——力量（攻+2/点）、根骨（气血+12 防+1/点）、灵性（法+2 法力+8/点）、敏捷（速+2/点），世界界面「✨ 加点」面板 +/- 分配，与装备加成合并经 `totalBonus` 进战斗主角属性。老存档迁移按等级补发潜能。
- **召唤兽**：个体实例（uid/物种/等级/经验）；捕捉入栏（上限 6，以人物当前等级入场）；出战宠物打怪分得一半经验、每级全属性 +8%（`petGrowth`）；宠物栏可切换出战、显示等级/属性/经验。初始宠物走 PETS 表、收服怪走 MONSTERS 表（`petBase` 统一取数）。
- **存档**：localStorage `shanhai-save-1`（职业/召唤兽个体/银两/背包/等级经验/装备加点/任务进度/位置/已清怪），读档自动迁移旧字段，选人界面「继续冒险」读取。

## 4. 关键技术与约定

- **分层**：`src/core/` 禁止 import DOM（引擎/内容/AI/世界逻辑），`src/render/` PixiJS，`src/ui/` DOM。指令与事件全部是可序列化纯对象——联机时客户端上行 `Command[]`、服务器跑同一份 `resolveRound` 下发事件流。
- **随机**：战斗内一切随机走 `core/rng.ts`（mulberry32，种子化），同种子+同指令结果可复现；世界掉落用 `Math.random`（无需回放）。
- **素材**：`tools/gen-assets.mjs` 程序化生成（调色板+像素模板），输出到 `public/assets/`，`manifest.json` 清单定义每角色帧序列/帧率/循环——想换手绘素材按清单文件名替换 PNG 即可。
- **调平衡**：数值全在 `src/core/content.ts`；跑 `#sim` 看胜率。
- **文档同步**：功能变化改 `docs/功能说明.md`，接口变化改 `docs/接口说明.md`，操作/使用变化改 `docs/使用方式.md`，进度与待办改本文件；每模块交付前跑 `npm run build`。
- **已知怪癖**：vite 热更新偶尔吃掉同批多次编辑的后半截（伺服模块新旧混合），症状是"改了没生效/报奇怪的错"——硬刷新或重启 dev server 解决。
- **调试句柄**：DEV 构建下 `window.__shanhai`（state/playerPos/info/moveTo），供自动化测试与调位置用。
