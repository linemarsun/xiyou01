# 桃源 / 云京 场景风格要点（按参考图实测整理）

> 参考图：大话西游2 长安城内一段街景（一张，已只读一次）。以下为后续作画的文字基准，不再回读原图。

## 1. 构图网格走向
- 斜 45° 等距（经典 2:1 等距）：街道中轴、院墙基座、屋脊、台阶踏步全部沿屏幕对角线方向延伸，屏幕斜率约 ±26.5°（水平走 2 像素、垂直走 1 像素）。
- 画面内不出现天空、地平线、远景山体；整幅由地面与建筑填满。
- 俯角约 50~55°：屋顶瓦面在画面中占据很大面积（约占单座建筑可见高度 55~65%），墙身只露出檐下到墙裙的上部一段。
- 地面铺装也按同一对角网格排布，砖缝方向与街道走向一致（团花拼花已改为横铺石条，见 §3）。

## 2. 瓦色与木色（v6 定稿调色板，取自角色同一套主色）
- 瓦：**靛青 `#2f4a5c`**（(47,74,92)），阴面压到 0.96 倍、受光棱提亮到 `#8faec0` 级；**不要翡翠亮蓝、也不要滑到近黑**（旧版 (42,66,84) 再叠重压暗会读成黑屋面，已废弃）。
- 逐栋瓦色微差：`(50,78,98) (61,89,108) (46,73,92) (66,92,100) (55,82,102)`，相邻屋面不连成死色。
- 屋脊：比瓦面深一档 `(26,44,58)`，脊宽 6px，脊面压一道 **赭金 `#b8892f`** 3px 金线（贴脊面 +5，不浮空）。
- 木构：**朱红 `#a63d2f`**（梁枋、立柱、格扇框），阴面 `#7c291f`；挂落下缘缀 2px 赭金线。
- 饰件：**赭金 `#b8892f`**（门钉、脊金、瓦当线、台基压边），面积要小。
- 墙面：**米白 `#f7f0dd`**，阴面 `#d6ccb6`，再暗一级 `#baaf9c`；形成"亮墙朱框"的对比。
- 石作（台基、栏板、石灯）：`#b0a999` / 阴 `#8b8476`，沿口一道亮棱。
- 地面石板：`#a8a496` `#8c8e89` `#bab4a6` `#787a75` 四档冷灰，缝 `#545048`；比墙面暗一档，避免地面与墙同亮度。

## 3. 地面材质
- 街道：三列长条石板错缝（板长 66、列宽 126、错缝 33），四边倒角（上 1.18 亮 / 下 0.74 暗），约三成石板带 2px 折线裂纹。
- 地坪（街区）：90×90 菱形砖，2×2 成簇换色阶，少数嵌小方砖做拼花，避免棋盘格。
- 拼花：不再做同心圆团花（会读成井盖），改为每 600 一条横铺石条跨街心。
- 苔痕：**只贴路缘与墙脚**（宽 10~16，暗青 `#5c653c`），街心不撒斑。
- 散落落叶（赭黄短划）、积水（不规则暗块 `#4e565c` + 一道亮棱，不做镜面）。
- 大面积地面不许"一整片同色"：靠缝、倒角、苔痕、水洼、落叶四层变化拉开。

## 4. 建筑层数与人物高度比（v6 实测）
- 角色单帧 128×128，**场景内屏高 84px**（纵深缩放 1.1×=92.4 / 1.0×=84 / 0.9×=75.6）。
- 主街临街立面：**檐口 z=152~165px（1.8~2.0×）**，**屋脊 z=196~209px（2.3~2.5×）**，含脊帽 ≤213。
- 后排次要屋面：檐口 116~148px，屋脊 160~194px（作为层叠背景，更矮）。
- 重檐：腰檐 z≈84，主檐 z≈158；重檐只增加一层，不做三檐。
- 台基高 16（门楼 24），台阶 3~5 级、每级进深约 6px、沿 +u 递升。
- **不许靠缩小进深来"假装变矮"**：屋顶坡面进深与开间比例固定（1 开间 90 宽配 135 瓦坡进深）。

## 5. 物件密度
- 沿街散布：旗幡（红布 + 暗金字，杆高约 1.6~2 倍角色）、灯笼串、马车、摊位、石灯 / 石幢、香炉、拴马桩、石狮。
- 物件沿街间距约 150~250 px（按 1440 宽计），成组出现，避免等距排列。
- 中央可并行走动的净宽约 3~4 个角色宽（250~330 px），物件只贴两侧，不侵入走道中线。

## 6. 光影与遮蔽
- 主光来自左上方、略偏暖，阴影统一投向右下（`+u` 方向偏移 `0.46 × h`）；同一画面只有一个光向。
- 赛璐璐两级明暗：受光平涂 + 1~3 档硬边阴影带（檐下 / 墙根各三级），带间用窄渐变过渡，**不做写实环境光遮蔽的连续渐变**。
- 檐下、墙根、台阶侧面、物件背光面压暗 40~50%，并偏冷（青灰）。
- 亮部只留小面积：屋脊受光边、瓦垄亮棱、石阶沿口、幡布受光面。
- 整体基调偏灰、中低对比：最亮处不做纯白，最暗处不做纯黑。
- 接触阴影（物件/建筑与地面交界）6~12px 软暗边，物件才"落"在地上。

## 7. 可复用构件画法（为后续模块化拼接预留）
- 统一对角网格：所有构件按同一 2:1 网格生成，锚点取 45px 整数倍。
- 单件构件（屋脊段、檐口、柱列、台阶、石灯、幡杆、摊位）各自独立成块，边缘留 6 px 余量。
- 石作、木构、瓦面分别用固定的 3~4 色阶，保证不同地块拼接时色调一致。
- 阴影方向固定为右下，构件自带接触阴影，拼装时无需再补。
- 完整清单（尺寸 / 可平铺性 / 对齐方式）见 [taoyuan_modules.md](taoyuan_modules.md)。

## 8. 斜俯视的遮挡规律（摆件前必须知道）
- 2:1 斜等距 + 26.5° 视向下，街两侧约 200px 高的屋面会遮住街道的**远段**。
- 街道在画面上不是一块矩形，而是一条**从画面右下贯到左上的斜带**；实际露出的主要是街左侧一段（world `u ≈ -790 … -690`）。
- 因此摊位、树、灯、幡、角色**只沿这条露出的斜带布置**；贴街沿的散件在深度排序时要 `+150` 偏置，否则会被自家屋面吃掉。
- 近侧（画面右下）的建筑基本只看到屋面，远侧才看得到正立面 —— 这是该视角的正常表现，不必强行补立面。

## 9. 与角色的画风统一（硬约束）
- 描边：场景所有形体统一 2~3px 深色描边（`#24201E`），抗锯齿（按 2× 超采样后降采样），屋檐口、屋脊、墙脚、树冠外缘、摊位轮廓、石狮边缘都要有。
- 平涂：先超采样到 2880×1800 再 LANCZOS 降到 1440×900，保证描边无阶梯。
- 去掉照片质感：无碎石噪点、无细碎反光、无柔和照片阴影；纹样全部用块面表达。
- 调色板即角色主色（见 §2），饱和度与角色一致，不再用发灰的水泥色。
