# 云京街景 地块 / 构件清单（供 720×450 模块化拼装）

## 0. 基本单位与对齐约定

- 1 世界单位 = 1 像素（按 1440×900 画面计）；高度 h 与屏幕 y 1:1 映射。
- 投影：`x = OX + (u - v)`，`y = OY + (u + v)/2 - h`，2:1 斜等距，两组边沿 ±26.5° 对角线。
- 地块：**720×450 = 16×10 个 45px 单元**；90px 为"大格"（2 单元）。区域内 7200×4500 = 10×10 块。
- 落点规则：所有构件锚点 `(u, v)` 取 **45 的整数倍**；建筑/墙体的锚点为"近角"（u1, v1），散件锚点为底部中心。
- 描边：统一 2~3px（深色 `#24201E`），构件四周预留 **6px** 余量，避免贴地块边缘被裁。
- 投影：统一朝 `+u` 方向偏移 `0.46 × h`，色 `(46,52,60)`、alpha 22、模糊 5px；构件自带，拼装时不补。
- 平铺周期：石板缝、瓦垄、墙裙均以 **45px** 为最小周期，因此在 720 / 450 的切线上天然对齐。
- 只画可见面：立面仅 `u = max` 与 `v = max` 两个面可见（另一侧朝画面外，不画）。

## 5. 拼装注意（100 块大地图）

1. **地块内构件允许跨切线**：切线处的 720 / 450 只是出图切分，不是构图约束；拼装时按世界坐标连续绘制即可，不要给地块单独收边或描边。
2. **排序**：建筑按 `u1 + v1`；散件与角色按 `u + v + 150`（偏置值），否则贴街沿的物件会被同一栋屋面盖掉。
3. **可见街带**：26.5° 俯角下，街两侧 200px 高的屋面会遮住街道远段；摆摊/树/灯只沿"露出的斜带"排布。
4. **颜色**：只允许使用调色板（见 `taoyuan_style_ref.md` §2），新增构件不得引入新色相，明暗只在 ±25% 内分级。
5. **角色基准**：单帧 128×128，场景屏高 84px；建筑檐口 152~165（≈1.9×），屋脊 196~209（≈2.4×）。
