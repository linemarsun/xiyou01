# 山海奇谭 · 设计要求

> 本文记录项目迭代至今**已确立并落地到代码**的设计要求与决策，是后续开发必须遵守的约束基线。
> 功能现状见 [功能说明.md](./功能说明.md)，接口见 [接口说明.md](./接口说明.md)，操作见 [使用方式.md](./使用方式.md)。
> 对应基线：`origin/dev` @ `95f0c1f`（v0.26.0 三十图 + 朝歌帝都体验）。

## 1. 世界观与地图拓扑

- **世界观**：《封神演义》改编（封神奇谭线），共 **30 张地图**：朝歌城、西岐城、五关三镇（界牌关/临潼关/穿云关）、渑池县、冀州、梅山、三仙岛、峨眉罗浮洞、北海、摘星楼、燕山、终南山、昆仑山玉虚宫、地府及各野图等。
- **朝歌 = 帝都中心**：舆图、出生地、传送枢纽均以朝歌为核心，形成"帝都枢纽"体验。
- **剧情八章**，最终 Boss 为鹿台决战的纣王·帝辛；梅山袁洪、云霄等为新增加强 Boss。

## 2. 城池与出生设计

- **出生地**：新档出生在**朝歌城**，出生点在长老**比干**身旁的御街（可走格已由回归锁定），出生点旁即土行孙传送 NPC。
- **安全城池**：**朝歌城与西岐城不设置任何怪物**（`spawns` 为空，布局 JSON 的 `anchors.spawns` 必须同步为空——回归会逐条比对两处）。安全城负责出生、接任务、传送，不被战斗打断。
- **司礼任务城**：朝歌（比干）与西岐（姜子牙）都可接/交付悬赏任务；其余图长老也可开"西岐司礼府·悬赏榜"。挂机决策把两城都识别为任务城，任务链完成后优先停止而非继续刷怪。
- 野图的悬赏目标怪（骷髅、蜘蛛、妖卒等）刷新不受安全城影响。

## 3. 舆图（map-panel）设计要求

- **四境全图必须收录全部地图**：禁止使用手工坐标表（旧的 `GRAPH_POS` 只有五图导致新图不显示）。新图只要 `exits` 拓扑连通即自动出现在舆图上，**无需登记坐标**。
- **布局算法**：以**朝歌为中心**的同心环放射布局——按出口拓扑 BFS 分层（7 层 7 环，半径逐层递增），节点角度按子树叶子比例瓜分圆周，再做**全局节点框成对松弛**防止重叠（回归与仿真验证重叠数 0）。
- **节点样式**：朝歌用 👑 金色帝都高亮；当前所在地红底高亮。
- **点图跳转**：点击四境全图节点 → **自动寻路到本图土行孙身旁 → 抵达触发圈后遁地直达目标图**（不再是走到出口路牌的多程跳转）。已在土行孙身边时立即跳转；中途改道/手动点地则跳转请求作废。手动靠近土行孙仍弹传送菜单，两种方式并存。「本境通路」按钮保持寻路到路牌的原始行为。

## 4. 传送系统设计要求

- **每图固定一名土行孙**（`WorldMap.teleporter` 字段，30 图全覆盖）：等距图默认站格网中心并渲染时吸附最近可走格，不卡建筑。
- 靠近约 80px 弹出「土行孙·遁地术」菜单，点选任意舆图**直接传送**，落点为该图土行孙身旁，复用 travel 的淡入重建与落地防弹回保护。
- 传送 NPC 青色名牌；舆图俯瞰与图例中标出土行孙位置。

## 5. 素材与美术要求

- **双素材线并存**：
  - **工笔线**（云京精修）：太和殿版宫城、宫墙 v7、宫门/角楼/白塔、9×9 合院等，位于 `iso/` 根目录；
  - **手绘线**（四图 hw 线）：位于 `iso/hw/` 子目录，`ISO_HW_MAPS` 按 `mapId` 前置分流（`isoModuleCandidates(type, variant, facing, mapId)`）。
- **西岐城（taoyuan 图）照搬 main 云京城布局**：648 构件（10×10 太和殿宫城 + 22 段无缝宫墙、四门 gate_keep 12×6 城台、24 座 9×9 大合院、鼓楼广场牌坊）。
- **民居贴图规格分流**：西岐城走 `house_9x9_*`（581×520 合院规格），其余 29 图走 `house_4x4_*`（273×327），渲染层按图分流；**禁止混用规格**（构件精灵 1:1 贴图不缩放，规格错配会压塌街巷）。
- **构件默认尺寸改动须知**：改 `ISO_TYPES` 默认 w/h 前必须核实所有布局 JSON 的构件都带显式尺寸（已核实三十图全部带显式 w/h，默认值只影响缺省图）。
- **宫墙无缝**：宫墙采用程序化整段生成（`tools/gen_palace_wall.py`，图案周期 = 段步进，相位差归零），禁止独立段端头贴图拼接。
- **地图布局约束**：建筑不得重叠；民居元素须差异化（变体池按格哈希分发）；新增 landmark 需满足投影遮挡约束（Δ(u+v)<15 且 Δ(u-v)<10 跳过）；重生成布局后必须补跑 `_add_market_green` + `_green_belt` 后处理。

## 6. 工程约束（持续有效）

- **回归测试守护**：`node tools/regression.mjs` 当前 **80/80 全部通过**是合入前提。改地图/素材/断言过期时**同步更新断言**（如 ISO_REGIONS 扩图后铺装组合数、地标按 `REGION_LANDMARKS` 主题表校验），不得删除测试规避。
- **锚点一致性**：`world.ts` 的 spawns/NPC/出口坐标与布局 JSON `anchors` 必须逐条一致（回归比对）。
- **类型零错误**：`npx tsc --noEmit` 必须干净；`src/core/` 禁止 import DOM。
- **端口约定**：dev 线服务端口 **5288**（main 线启动加固版 vite 配置，避开 5199 冲突）。
- 存档兼容：改出生点/地图拓扑时注意旧存档迁移（落地保护会吸附到最近可走格，避免卡死）。
