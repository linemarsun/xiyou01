# 山海奇谭 · 使用方式

> 面向玩家与开发者：安装运行、完整操作流程、调数值、换素材、存档与排障。
> 功能清单见 [功能说明.md](./功能说明.md)，接口签名见 [接口说明.md](./接口说明.md)。

## 1. 环境与运行

需要 Node.js ≥ 18（当前开发环境为 v22.22.2 / npm 10.9.7）。

```bash
cd shanhai
npm install
npm run dev        # 打开 http://localhost:5199
```

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 开发服务器，端口 5199，改代码热更新 |
| `npm run build` | `tsc --noEmit` + `vite build`，产物 `dist/` |
| `npm run preview` | 预览构建产物 |
| `npm test` | 跑 `tools/regression.mjs` 全链回归自检（Node 侧，无需浏览器） |
| `npm run assets` | 重新生成全部像素素材（会清空重建 `public/assets/`） |

> `npm run assets` 依赖 `pngjs`（devDependency），只在换美术风格时需要跑；游戏运行不依赖它。
> `npm test` 用 esbuild 把 `src/core/` 打包成 ESM，在 Node 里注入 localStorage 替身后跑断言：任务链三环、战斗结算与存档迁移、加点/装备/师门、召唤兽、战斗可复现性、捕捉规则、素材清单契约。**新增玩法模块时请在 `tools/regression.mjs` 补对应断言**。

## 2. 一局游戏的完整流程

1. **选人**：取名号（≤8 字）→ 选门派职业 → 选初始宠物 → 点「开始冒险」。若已有存档，顶部会出现「继续冒险」（新开一局会覆盖旧存档）。
2. **云京**：点地面走路；靠近「玄鹤长老」会弹出**云纹木框悬赏榜**接取/交付任务；靠近「云京酒肆掌柜」雇佣同道；点「青崖山道」路牌自动走过去切图。HUD 的「📜 悬赏」可**随时只读查看**当前任务名、描述、进度条与赏格，但接取/交付仍需走到长老面前。地图是**横向长卷轴**（8 个区段，约 11520 px 宽），用国风满幅场景横向镜像拼接，镜头跟随卷动；长老与酒肆只在起点区段，跑远了要往回走；每 2 个区段有一组完整出口路牌。
3. **野外**：地图上怪物会游荡，靠近即触发遭遇战；点怪物/路牌/NPC 会自动吸附走过去。切图会重新刷怪。
4. **战斗**：见第 4 节。
5. **结算**：显示银两、丹药、装备、经验、升级、任务进度；点「返回」回地图，怪物组已清除，HUD 更新，进度自动存档。
6. **交任务**：任务达成后回云京找长老「领取赏银」，任务链推进到下一环。

三环任务：青崖清狼（青崖苍狼 ×3）→ 忘川镇骨（忘川骨卒/幽丝蛛妖 ×4）→ 洞天讨魈（洞天山魈王 ×1）。

## 3. 世界界面 HUD 与面板

顶部 HUD 显示：地图名、等级/经验、银两、金疮药 / 凝气丹 / 洗点丹数量、出战召唤兽、任务进度。右侧按钮：

| 按钮 | 用途 |
| --- | --- |
| ✨ 加点 | 用潜能点分配力量/根骨/灵性/敏捷，`+` 加点、`−` 退点；底部可**使用洗点丹**清空加点并全额退还潜能点 |
| 📜 师门 | 用银两 + 潜能点修炼本门派法术等级（最高 Lv.10），显示当前等级效果与耗蓝 |
| 🐾 宠物 | 查看全部召唤兽（等级/属性/经验/技能/成长系数），切换出战宠物；底部「⚗ 炼妖」用两只**非出战**召唤兽合成一只（100 银）；上限 6 只 |
| 🎒 背包 | 人物三部位 + **出战召唤兽的护甲/饰品两个装备位**；装备、给宠物装备、卸下、炼化（30 银重掷词条）；★ 为极品稀有词条；上限 12 件 |
| 🤖 挂机 | 一键托管：自动寻路找怪 → 自动战斗 → 跨图巡游 → 自动回镇接/交任务；再点一次停止 |
| 🔊 / 🔇 音效 | 切换静音（选人界面、战斗页也有同款按钮），偏好会记住 |
| 💾 菜单 | 保存当前位置并回到选人界面 |

游戏有 **三档自动合成的 BGM**（选人 / 世界 / 战斗）与战斗事件音效，全部由 Web Audio 实时合成、无音频素材文件。浏览器要求首次点击/按键后才会开始播放，这是正常现象。

**国风美术**：UI 采用云纹木框面板 + 朱红/靛青/赭金/米白主色，选人卡片用 Q版国风头像，战斗道具用国风图标，战斗背景为满幅国风场景（云京 / 青崖山道 / 玲珑洞天 / 渡忘川）。战斗精灵与世界分块场景仍由程序化生成器绘制（统一到同一套国风配色），以保留帧动画与平铺能力——参考素材本身不含序列帧、也不支持无缝平铺。想调整某个实体用哪张图，改 `src/core/art.ts` 的映射表即可，无需改渲染代码。

装备与人物、召唤兽**共用背包**，同一件装备不能被两方同时穿戴；人物加成与宠物加成各自独立，均**下一场战斗生效**。

**炼妖规则**：物种二选一、等级取两者较高、经验清零，技能取双方并集去重后最多 3 个；20% 概率额外领悟 1 个通用技能（噬血爪 / 玄岩甲 / 引雷诀）；结果获得 `×1.00~1.20` 随机成长系数叠乘在全属性上。装备不继承、出战宠物不变。参与的两只都会消失，请先确认。

**组队同伴**：酒馆提供 3 种同伴（忘川引灯人 / 琼霄云游使 / 玄炎墨刀客），各 150 银、最多同时 2 名，解雇不退款。同伴进入人物排，**每个同伴在战斗指挥阶段都要单独下指令**（自动战斗会一并接管），但不能使用捕捉；同伴不吃经验，等级始终跟随人物等级。HUD 的 `👥 同伴 N/2` 可查看当前人数。

**挂机（自动战斗 + 自动寻路）**：点 HUD「🤖 挂机」即开始——自动走向当前地图最近的怪、自动触发战斗并自动下指令、结算后继续下一组；当前图清空会自动切到下一张图，任务达成会自动回云京找长老接/交任务并领取奖励。再点一次即可停止。以下情况也会自动停机并提示原因：**战斗败北、金疮药与凝气丹同时耗尽、任务链全部完成、没有可打的怪、或在战斗内手动关掉自动战斗**（手动优先）。挂机状态不存档，**刷新页面后自动关闭**。

寻路目前是「直线走到目标 + 可行走区钳制 + 点路牌/NPC/怪物自动吸附」，地图没有障碍物数据所以不绕障；点击移动与挂机移动共用同一条路径管线。**当前没有商店系统**，所以补给只来自任务奖励的丹药，药品耗尽需你手动补充后再开挂机。

## 4. 战斗操作

大话式流程：**回合开始为所有己方单位依次下指令 → 点「出手」按速度结算**。

- 攻击 / 法术 / 道具 / 捕捉：先选动作，再**点场景中的单位**选目标（法术面板显示等级与耗蓝，法力不足的按钮禁用）。
- 防御：直接对该单位下达，本回合受伤减半。
- 捕捉：仅人物可用，目标气血越低成功率越高；洞天山魈王不可收服。
- 「⤺ 重选上一人」可撤销上一条指令；全部下完后出现「出手！」。
- **▶ 自动**：开启后由 AI 接管（同源策略 + 气血 <40% 自动嗑金疮药）；出手前关掉即可回到手动指挥。
- **速度 ×1 / ×2**：切换事件播放速度。
- 右侧战斗记录逐条播报，画面有血蓝条、状态章、伤害飘字、法术粒子与倒地动画。

道具每场按**背包存量**带入（金疮药回血 200 / 凝气丹回蓝 90），战斗结束按实际消耗回扣背包；胜败都扣。**洗点丹不进入战斗**，只能在世界界面的「✨ 加点」面板使用。

## 5. 数值仿真（调平衡用）

地址栏加 `#sim`（如 `http://localhost:5199/#sim`）进入仿真页：AI 执挥双方，每职业 36 场、三种遭遇轮换，输出胜率与平均回合数。改完 `src/core/content.ts` 刷新即可看到新结果；点「返回游戏」回到正常流程（hash 变化会整体重载）。

| 想改什么 | 改哪里 | 备注 |
| --- | --- | --- |
| 职业技能/威力/命中、怪物属性、抗性、道具、遭遇编成 | `src/core/content.ts` | 改完刷新即生效 |
| 伤害公式、会心率、状态递减、捕捉率 | `src/core/battle.ts` | 涉及全部战斗平衡，改后建议跑 `#sim` |

| 稀有词条概率与倍率 | `src/core/equipment.ts`（`RARE_AFFIX_CHANCE` / `RARE_AFFIX_MULT`） | 极品装备每次炼化都会重新判定 |
| 掉落品阶池 / 洗点丹掉率 | `src/core/world.ts`（`DROP_TIER_WEIGHTS` / `RESPEC_DROP_CHANCE`） | 一组怪取品质期望最高者的权重 |

| 挂机巡游路线、重决策间隔、路径策略 | `src/core/autoplay.ts`（`AUTO_ROUTE` / `nextAutoAction`）、`src/core/path.ts`（`planPath`）、`ui/world-screen.ts`（1600ms 定时器） | 无障碍物数据，替换 `planPath` 即可接入 A* |

| 国风素材映射 / 主色 / 场景调色板 | `src/core/art.ts`（`ART_THEME` / `CLASS_ART` / `SCENE_ART`）、`src/style.css`、`tools/gen-assets.mjs`（`SCENES` / `WORLD_SCENES`） | 换图改映射表；改配色后跑 `npm run assets` |
| 地图出生点、出口、任务目标、掉落率、经验表 | `src/core/world.ts` | `WORLD_MAPS` / `QUESTS` / `SILVER_PER_KILL` / `EXP_PER_KILL` |
| 敌方 AI 行为 | `src/core/ai.ts` | 自动战斗同源，改动会同时影响两者 |

## 7. 换美术素材

素材全部由 `tools/gen-assets.mjs` 程序化生成（原创像素画，零版权风险）：

- **调整风格**：改生成器里的调色板 / `CHARS` 造型参数 / `SCENES` / `WORLD_SCENES`，然后 `npm run assets`。
- **换成手绘或外部素材**：按 `public/assets/manifest.json` 里列出的文件名逐张替换 PNG，文件名与清单一一对应即可，代码无需改动。
- **新增怪物/职业**：必须同时在生成器的 `CHARS` 里加对应 key，使 `manifest.json` 出现该 defId 的帧序列；否则该单位不会被渲染。

清单格式与各动画字段含义见 [接口说明.md 第 11 节](./接口说明.md)。

## 8. 存档管理

- 键名：`localStorage['shanhai-save-1']`，内容为 `GameState` 的 JSON。
- 自动存档时机：接/交任务、战斗结算、切图、加点、修炼、装备穿戴/炼化、切换出战宠物、返回菜单。
- 读档时 `loadGame()` 会对旧存档缺字段做兜底迁移（宠物个体化、等级、装备、加点、按等级补发潜能）。
- 清空：选人界面点「开始冒险」会 `clearSave()` 后重开；也可在浏览器 DevTools 执行 `localStorage.removeItem('shanhai-save-1')` 后刷新。
- 目前**没有存档版本号，也没有导入/导出功能**；跨版本升级依赖字段兜底，勿手工改 JSON 结构。

## 9. 调试（DEV 构建）

浏览器控制台可用 `window.__shanhai`：

```js
__shanhai.state()          // 当前 GameState
__shanhai.playerPos()      // 玩家地图坐标
__shanhai.info()           // 渲染器内部状态（player/cam/target/engaged）
__shanhai.moveTo(720, 600) // 直接走到地图坐标，便于自动化或定位
```

生产构建不挂载该句柄。

## 10. 常见问题

| 现象 | 处理 |
| --- | --- |
| 改了代码"没生效"或报奇怪的错 | Vite 热更新偶尔吃掉同批多次编辑，硬刷新或重启 dev server |
| 画面白屏 / 单位不显示 | 检查 `public/assets/manifest.json` 是否存在、对应 defId 的帧文件是否齐全；新增角色需重跑 `npm run assets` |
| 点不动地面 | 行走区域限制在 `WALK_BOUNDS`（x 60~1380，y 478~862），远景不可走 |
| 法术按钮灰色 | 当前法力低于该法术等级的 MP 消耗；或用凝气丹 / 等回合末自动回蓝 |
| 捕捉总是失败 | 先把目标打残（成功率随残血提升）；头目 `shanxiaowang` 不可收服 |
| 装备/加点没效果 | 加成在**下一场战斗**生效，不会改变当前战斗中的属性 |

## 11. 开发约定

- 新增玩法逻辑放 `src/core/`，且**不得 import DOM**；指令与事件必须是可序列化纯对象。
- 战斗内随机一律走 `core/rng.ts`（种子化），世界侧随机可用 `Math.random()`。
- 渲染层只消费事件流，不直接改引擎状态；DOM 面板展示用状态从 `Battle.snapshot()` / 事件增量维护。
- 每个模块交付前跑 `npm test` + `npm run build`；数值改动后跑 `#sim` 看胜率。
- 代码与文档同步：功能变化更新 [功能说明.md](./功能说明.md)，接口变化更新 [接口说明.md](./接口说明.md)，操作变化更新本文，进度与待办更新 [../PROGRESS.md](../PROGRESS.md)。
